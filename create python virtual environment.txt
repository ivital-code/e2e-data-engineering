docker compose -f docker-compose.yml up -d
docker compose
Uses Docker Compose V2 to manage multi-container applications.
-f docker-compose.yml
Specifies the Compose file to use.
If omitted, Docker Compose looks for docker-compose.yml or docker-compose.yaml in the current directory.
up
Creates and starts the services defined in the Compose file.
It also creates networks and volumes if needed.
-d
Runs the containers in detached mode.
The command returns immediately and the services keep running in the background
