KAFKA_BOOTSTRAP_SERVERS=broker:29092 means:

KAFKA_BOOTSTRAP_SERVERS
This is the address your app uses to initially connect to Kafka and discover the cluster metadata.

broker
This is the Docker Compose service name for the Kafka container. Inside the same Compose network, containers resolve broker as a hostname automatically.

29092
This is usually the internal Kafka listener port used for container-to-container communication.

Why this is common in Docker Compose:

Apps running inside Compose use broker:29092.
Apps running on your host machine usually cannot use broker, so they use localhost:9092 (or whatever host port is mapped).
Quick rule:

Inside Docker network: broker:29092
Outside Docker network (host tools/scripts): localhost:9092
